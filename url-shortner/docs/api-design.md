# Core API
- Register user
  - Endpoint: POST /auth/register
    This endpoint takes username and password. The hash of password is stored in the database and the server responds with JWT which will be used by the user (provided in the header of each request) to authenticate requests.
  - Headers:
    ```http
    Content-Type: application/json
    ```
  - Sample Request:
    ```json
    {
        "username": "unique-username",
        "password": "strong-password"
    }
    ```
    - username (required): Unique string acting as identifier for user.
    - password (required): string whose hash needs to be stored on database.
  - Sample Response:
    ```json
    {
        "token": "saMPleJwTTokENWhiChWilLbEUSeDTOautHEnTiCAteUSer"
    }
    ```
  - Error case:
    - Conflict (409): If username already exists.
    - Bad Request (400): Missing required fields.
    - Too many requests (429): crossed rate limit for registration.

- Login user
  - Endpoint: /auth/login
    It takes username and password. This username along with hash of password is verified with the already existing one and then JWT is generated which will be used to make requests.
  - Headers:
    ```http
    Content-Type: application/json
    ```
  - Sample Request:
    ```json
    {
        "username": "existing-username",
        "password": "existing-password"
    }
    ```
    - username (required): Existing unique string acting as identifier for user.
    - password (required): string whose hash needs to be verified against the hash stored on database.
  - Sample Response:
    ```json
    {
        "token": "saMPleJwTTokENWhiChWilLbEUSeDTOautHEnTiCAteUSer"
    }
    ```
  - Error case:
    - Unauthorized (401): Invalid username or password.
    - Bad Request (400): Missing required fields or failed validation (e.g., password too short).
    - Too many requests (429): Crossed rate limit for authentication.

- Create short URLs
  - Endpoint: POST /shorten
    This endpoint takes a long URL (and optional parameters) and generates a corresponding short URL.
  - Headers:
    ```http
    Authorization: Bearer <token>
    Content-Type: application/json
    ```
  - Sample Request:
    ```json
    {
        "long_url": "https://example.com/very/long/url/that/needs/shortening",
        "custom_alias": "",
        "expires_at": "2024-12-31T23:59:59Z"
    }
    ```
    - long_url (required): The original URL that needs shortening.
    - custom_alias (optional): A user-defined alias for the short link (e.g., /my-link). If provided, the system validates uniqueness.
    - expires_at (optional): Timestamp when the short link should expire. If omitted, the link is permanent (or defaults to a system-wide policy)
  - Sample Response:
    ```json
    {
        "short_url": "https://short.url/abC1234",
        "long_url": "https://example.com/very/long/url/that/needs/shortening",
        "expires_at": "2024-12-31T23:59:59Z",
        "created_at": "2024-08-10T10:30:00Z"
    }
    ```
    - short_url: The shortened link generated by the system.
    - long_url: The original URL.
    - expires_at: The expiration timestamp (if set).
    - created_at: When the short link was created.
  - Error Cases:
    - Conflict (409): If a custom alias already exists.
    - Bad Request (404): If the URL is invalid.
    - Unauthorized (401): If the token is invalid.
    - Too many requests (429): If number of requests cross the rate limit.

- Redirect to Long URL
  - Endpoint: GET /{short_code}
    This endpoint takes the short URL key and redirects the user to the corresponding long URL.
  - Sample Response:
    ```http
    :status: 302
    Location: https://example.com/very/long/url/that/needs/shortening
    ```
    - Found (302): Default. The browser contacts the service on every click, which preserves click tracking and lets us update or expire links.
    - Moved Permanently (301): Optional, for links that never change. It is faster on repeat visits, but the browser caches the destination and stops contacting the service, so click tracking is lost.
  - Error cases:
    - Gone (410): If the link has expired.
    - Not Found (404): If the link does not exist.

- Get URL Analytics:
  - Endpoint: GET /analytics/{short_code}
    Retrieves click statistics for a short URL.
  - Headers:
    ```http
    Authorization: Bearer <token>
    Content-Type: application/json
    ```
  - Sample Response:
    ```json
    {
        "short_code": "abc1234",
        "total_clicks": 15420,
        "created_at": "2024-08-10T10:30:00Z",
        "last_accessed": "2025-01-20T14:22:00Z"
    }
    ```
  - Error cases:
    - Unauthorized (401): If the token is invalid.
    - Not Found (404): short code not found
    - Forbidden (403): If the user do not have permission to view analytics (JWT against userID do not relate to short_code).
